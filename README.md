This repository documents my complete journey through **[Code in Place 2026](https://codeinplace.stanford.edu/)** , a free, online introductory programming course offered by **Stanford University**. The course is based on the first half of Stanford's legendary CS106A "Programming Methodology" and teaches the fundamentals of Python.

## 📌 About the Course

Code in Place is a unique, community-driven program. Over **6 weeks**, students from around the world learn together in small, interactive sections led by volunteer teachers. The curriculum starts with **Karel the Robot** to build logical thinking without syntax complexity, then transitions to Python programming covering:

- **Control Flow:** `while` loops, `if/else` conditions, and `for` loops.
- **Functions & Decomposition:** Breaking down complex problems into smaller, reusable pieces.
- **Data Structures:** Lists, dictionaries, and file I/O for persistent data.
- **Graphics & Events:** Creating interactive graphical programs.
- **Final Project:** Applying everything learned to build a personal project.

The course emphasizes problem-solving, code clarity, and the joy of creating with code.

### 🚀 A Closer Look at My Work

#### 🤖 Karel the Robot (Logic & Decomposition)

The Karel section was a fantastic way to start. Without using variables or complex arithmetic, I strengthened core skills:

- **Problem Decomposition:** Breaking `Midpoint` finding into small, repeatable steps.
- **State Management:** Using beepers as physical markers in `Checkerboard Karel` to maintain pattern consistency across even/odd dimensions.
- **Conditional Navigation:** Having Karel navigate and clear a `Steeplechase` track with walls of varying heights.

These foundational exercises in logical thinking have proven invaluable for the Python that followed.

#### 🐍 Python Progression

From Week 3 onward, I translated those logical skills into Python syntax. My weekly folders show a steady progression:
- Mastering `while` and `for` loops.
- Writing clean, well-documented functions.
- Managing data with `list`s and `dict`s.
- Reading from and writing to files to save data between runs.
